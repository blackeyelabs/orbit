# Canvas editing is deferred until after Phase 3

`.canvas` (JSON Canvas) files are supported only in a limited way until graph view and plugins are in scope: they show in the tree, the text in their cards is indexed for search, and opening one shows a "Canvas editing isn't available yet" message. A canvas editor is a second custom editor about as large as Live Preview, and the design doc names scope creep as one of its top risks for a solo developer.
