`orbit-paper.json` maps the design canvas's theme sheet (Main.dc.html) onto
GPUI Kit's theme keys. Every colour is a canvas token, except the text
colours on danger and info fills, which the canvas doesn't define: they use
the raised paper (#F6F3EC) on Orbit Paper and the paper (#211F1C) on Orbit
Paper Dark, matching how the canvas sets text on green.
